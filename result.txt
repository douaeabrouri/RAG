question = How do you install vLLM with a specific CUDA version using pip?
Answer = To install vLLM with a specific CUDA version using pip, set the `CUDA_VERSION` environment variable in the pip install command. For example:  
```bash  
export CUDA_VERSION=118 # or 126  
uv pip install --extra-index-url https://download.pytorch.org/whl/cu${CUDA_VERSION} vllm  
```  
This ensures vLLM uses the specified CUDA version.
